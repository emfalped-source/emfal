# Coordenador Virtual

Apoio à decisão da coordenação pedagógica: analisa o caso (saúde, comportamento, frequência, pedagógico), sugere o nível de encaminhamento e deixa a mensagem pronta para o WhatsApp do responsável. A decisão é sempre do coordenador.

- Uso pessoal: entra com uma senha própria, separada do login dos apps da EMFAL.
- Dados (contatos e histórico de casos) numa planilha do Google Drive de quem publica o servidor (`servidor/Codigo.gs`). Nada de dado de estudante fica neste repositório.
- Instalável no celular (PWA): no Chrome, menu ⋮ › Instalar app / Adicionar à tela inicial.

Endereço: https://emfalpbh.github.io/emfal/coordenador/
